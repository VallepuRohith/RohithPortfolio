# Crimson Canvas

Build a modern, premium, visually rich personal portfolio website for me.

IMPORTANT:

The uploaded image is my current portfolio screenshot. Use it only as a reference for the type of content and general portfolio structure. DO NOT copy its UI, gray background, layout, typography, or visual style.

I want a completely new design with rich bright colors, strong visual hierarchy, smooth animations, interactive sections, and a premium developer-portfolio feel.

PERSONAL DETAILS

Name: Vallepu Rohith

Role: Software Developer and Instructor

Portfolio type: Personal developer portfolio

CORE DESIGN DIRECTION

- Bright, modern, premium visual design

- Avoid the boring gray/white corporate look from the reference image

- Use a rich burgundy-based color palette with deep wine, crimson, muted rose, and subtle warm gradients.

 Use dark burgundy/deep wine backgrounds with lighter burgundy, cream, and soft rose accents for contrast.

- Use large typography and strong visual hierarchy

- Use glassmorphism selectively, not excessively

- Add subtle glow effects, gradient borders, animated backgrounds, and floating UI elements

- The website should feel like a modern tech product rather than a traditional resume website

- Keep it professional and recruiter-friendly

- Do not make it look like a gaming website

- Avoid excessive animations that hurt readability or performance

- Fully responsive on desktop, tablet, and mobile

TECHNOLOGY

Use:

- React

- TypeScript

- Tailwind CSS

- Framer Motion / Motion for animations

- Lucide icons

- Modern component architecture

- Smooth scrolling

- CSS gradients and subtle visual effects
